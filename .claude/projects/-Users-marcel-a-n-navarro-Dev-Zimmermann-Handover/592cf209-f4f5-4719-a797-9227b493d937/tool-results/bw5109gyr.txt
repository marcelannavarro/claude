## Design layer

### Overview

`<zimm-add-to-wishlist>` is an icon toggle button that adds or removes a product from the user's wishlist. It renders a `wishlist` icon in the unselected state and a `wishlist-selected` icon in the selected state. Clicking toggles the `selected` attribute and fires a `zimm-wishlist-change` custom event. Used within `<zimm-product-card>` and directly on product pages.

### Tokens used

| Token | CSS Variable | Used by |
|---|---|---|
| Icon size large | `--zimm-icon-size-lg` | Button width and height (20px) |
| Border width default | `--zimm-border-width-default` | Focus ring width |
| Border focus | `--zimm-color-border-focus` | Focus ring colour |

### Interactive elements

| Element | Action | Node ID |
|---|---|---|
| Button | Tap/click toggles `selected` attribute; fires `zimm-wishlist-change` | - |

### States

| State | Value | Note | Node ID |
|---|---|---|---|
| default | `selected` absent | Renders `wishlist.svg`; `aria-label="Add to wishlist"` | - |
| selected | `selected` present | Renders `wishlist-selected.svg`; `aria-label="Remove from wishlist"` | - |
| focus | `:focus-visible` | Outline: `var(--zimm-border-width-default) solid var(--zimm-color-border-focus)`, offset 2px | - |

## Design layer

### Overview
The Footer is the full-width dark site footer. It renders at three breakpoints: Desktop (1440px), Tablet (1024px), and Mobile (402px). No interactive states. It is a static organism. The dark background (`#191919`) and bottom bar (`#282828`) distinguish it visually from the page body.

### Element
`<zimm-footer>`: organism. Composes `<zimm-logo>` (atom, inverse variant), `<zimm-icon>` (atom), and `<zimm-input-action>` (molecule, newsletter subscribe).

Library files: [02-design/library/elements/footer/](../../library/elements/footer/)

**Responsive:** Layout breakpoints handled entirely by CSS `@media` queries inside the component shadow DOM. No attributes needed. Resize the browser and the layout adapts automatically.

<!-- design-layer: designer-owned. Do not edit below this line if you are a developer -->
## Design layer

### Overview

`<zimm-mega-menu>` is the panel content component for each navigation section. It renders a two-panel layout: a left panel containing category links and an optional personalised product module, and a right panel containing a full-height editorial image. One instance of this component is placed per navigation category into the corresponding named slot in `<zimm-navigation>` (`menu-new`, `menu-clothing`, `menu-accessories`, `menu-collections`, `menu-z-immerse`).

The component is passive: it renders content and fills its container. Open/close state is managed entirely by `<zimm-navigation>`.

| Background 07 | `--zimm-color-bg-07` | Host background |

| Text muted | `--zimm-color-text-muted` | Personal module label |
| Scale 300 | `--zimm-scale-300` | Personal label margin-bottom |
| Scale 1000 | `--zimm-scale-1000` | Left panel horizontal padding, all-wrap margin-top, two-column gap |
| Scale 1200 | `--zimm-scale-1200` | Left panel top padding, personal module padding-top |
| Font family body | `--zimm-font-family-body` | Links and personal label |
| Font size 3xs | `--zimm-font-size-3xs` | Links (12px) and personal label |
| Font lineheight 3xs | `--zimm-font-lineheight-3xs` | Links |

<!-- design-layer: designer-owned. Do not edit below this line if you are a developer -->
## Design layer

### Overview
The Navigation component is the site-wide header bar. It renders at three breakpoints (Desktop, Tablet, Mobile) with two states. Default is the resting bar. Active is triggered when a nav link is selected (Desktop/Tablet) or the hamburger icon is pressed (Mobile). In the Active state the bar triggers a full-width panel that slides down from the base of the bar over 300ms, covering the page content below. Both the bar and the panel use a white background. The panel content (links, imagery) is out of scope for this spec.

### Element
`<zimm-navigation>`: organism. Composes `<zimm-nav-item>` (atom), `<zimm-icon>` (atom), and `<zimm-mega-menu>` (molecule).

Library files: [02-design/library/elements/navigation/](../../library/elements/navigation/)

**Responsive:** Layout breakpoints are handled entirely by CSS `@media` queries inside the component's shadow DOM. There is no `size` attribute. Resize the browser window and the component adapts automatically: ≥1024px = Desktop, 768-1023px = Tablet, ≤767px = Mobile.

**Interaction:** The `active` attribute is toggled internally by click handlers. Nav link click (Tablet/Desktop) or hamburger tap (Mobile) sets `active`. Close button or X tap removes `active`. The attribute is also settable externally for prototype forcing.

### Tokens used
| Token | CSS Variable | Used by |
|---|---|---|
| `--alias/color/bg/page` | `--zimm-color-bg-page` | Nav bar background; mega menu panel background |
| `--alias/color/text/default` | `--zimm-color-text-default` | All nav link labels, Close label |
| `--alias/color/border/field/focus` | `--zimm-color-border-focus` | Active nav-item border-bottom; search input border |
| `--default/navigation` | `--zimm-font-size-3xs` (12px) via `.zimm-text-nav` | Nav link text size |
| `--alias/space/padding/1000` | `--zimm-scale-1000` (40px) | Horizontal padding, Desktop and Tablet |

<!-- design-layer: designer-owned. Do not edit below this line if you are a developer -->
## Design layer

### Overview

`<zimm-product-showcase-blocks>` is a molecule that combines a large hero card with a 2-column grid of product cards. Both the hero and the product cards use `zimm-card-baseline`. The hero card is wider and taller (664px wide, 1047px image height) while the product cards are standard size (288px wide, 438px image height). Used on campaign pages and collection pages to present a featured product alongside shoppable items.

The hero column is 664px wide. The product grid occupies the other column (two 288px columns, 100px column gap, 50px row gap). Total layout width is 1440px. An optional category links aside occupies the grid cell diagonally opposite the hero.

### Composes

- `zimm-card-baseline`
- `zimm-cat-links-aside` (optional)

### Variants

| Variant | Attributes | Notes |
|---|---|---|
| Default | (none) | Hero left, 4 product cards stacked from top |
| Hero right | `editorial-position="right"` | Hero right, products left |
| 2 cards bottom-aligned | `align-products="end"` | 2 product cards anchored to the base of the hero height |
| With aside, hero left | `slot="aside"` filled | Aside top-left of product grid, adjacent to hero |
| With aside, hero right | `editorial-position="right"` + `slot="aside"` filled | Aside top-left of full layout (product grid is on the left) |

### Slots

| Slot | Content | Notes |
|---|---|---|
| `hero` | One `zimm-card-baseline` | Hero column. Width = `--hero-width` (664px). Image height = `--hero-card-image-height` (1047px), yielding a 664x1149px card. |
| `product` | 1-4 `zimm-card-baseline` | Auto-placed into 2-column grid |
