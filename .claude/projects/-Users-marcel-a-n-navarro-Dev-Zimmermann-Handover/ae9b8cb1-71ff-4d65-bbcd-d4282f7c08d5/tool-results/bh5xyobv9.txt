Following up from the thread above — proposing AC updates so this is ready to automate (Gherkin/Zephyr). Rotation timing is now a configurable per-message duration rather than a calculated value, and persistence is cookie-based, so updating 2 and 6 accordingly, plus adding new ACs for category/product targeting and accessibility.

**Proposed AC updates:**

1. Given the promotional banner is configured with multiple messages, when the page loads, then each message is displayed for a configurable duration (in seconds, set per message in Contentful) before automatically rotating to the next message in the configured sequence.

1. Given a shopper closes the banner by clicking 'x', when they navigate to another page or reload within the same browser session, then a cookie records the closed state and the banner remains hidden site-wide until the cookie expires or is cleared.

1. *(new)* Given the promotional banner is placed on a PDP or PLP via Contentful Studio, when it is configured with one or more SFCC Category IDs and/or Product IDs, then the banner is only displayed when the shopper is viewing a matching category or product page.

1. *(new, draft)* Given a shopper is navigating via keyboard, when they tab through the page, then the banner's CTA link and close ('x') control each receive visible focus in a logical order and are operable via Enter/Space.

1. *(new, draft — pending the open question below)* Given the banner auto-rotates between messages, when a new message displays, then the change is announced to assistive technology via an `aria-live="polite"` region, without interrupting the user's current screen reader focus.

**Open question — play/pause:**

Closing the banner removes it entirely for the session, but WCAG 2.2 SC 2.2.2 (Pause, Stop, Hide) requires auto-updating content running longer than 5 seconds to be pausable without being dismissed outright. Do we want a distinct pause-on-hover/focus (a common accessible pattern) or a dedicated pause control, separate from close? This also determines whether AC 9 needs a "pause on focus/hover" clause added.

Squad ownership for test tagging will be confirmed at sprint planning — not blocking on that here.
