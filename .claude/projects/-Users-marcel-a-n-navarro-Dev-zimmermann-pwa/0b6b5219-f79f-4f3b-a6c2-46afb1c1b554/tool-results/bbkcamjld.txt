    fix(ui-kits): replace :focus-within with :has(:focus-visible) in ZimmProductCard hover reveals (SFCC-236)
    
    Live-browser testing surfaced a real bug in the arrows hover-gating fix
    from the previous commit: hovering the card correctly revealed the
    carousel arrows, but moving the mouse out did not hide them again —
    they stayed visible until a click landed outside the card entirely.
    
    Root cause: clicking an arrow button gives it real DOM focus in every
    evergreen browser engine, so the recipe's `&:focus-within` reveal
    stayed true after the mouse left, since focus doesn't clear on
    mouseleave. The identical shared-root mechanism underlies every other
    hover reveal in this recipe too (price show, price hide, the
    size-selector, notify-me), so a click on a size chip or the notify-me
    button would reproduce the same stuck-open symptom — confirmed and
    fixed across all five occurrences, not just the carousel one that was
    reported.
    
    `:has(:focus-visible)` fixes this: it only matches when the browser's
    own heuristic says a keyboard focus ring is warranted, which a
    mouse-click-focused <button> never satisfies in any evergreen engine,
    while genuine Tab navigation still does — so keyboard parity (the
    reason a focus-based reveal exists at all) is preserved and the
    mouse-click case is not. First use of :has() in this codebase; fully
    covered by the project's own browserslist (iOS >= 17, Android >= 14,
    last 4 ChromeAndroid versions), all past its 2022/2023 shipping
    baseline.
    
    Running the full test file (not just in isolation) surfaced a real
    jsdom+nwsapi quirk: a later plain .focus() call stops satisfying
    :has(:focus-visible) once an earlier test in the same file has driven
    a real userEvent.click()-originated focus. Fixed by switching that
    assertion to a real simulated Tab keypress (`user.tab()`) instead of
    an imperative .focus() call — arguably a more faithful test of
    "keyboard user tabs into the card" to begin with. Verified
    deterministic across repeated full-file runs.
