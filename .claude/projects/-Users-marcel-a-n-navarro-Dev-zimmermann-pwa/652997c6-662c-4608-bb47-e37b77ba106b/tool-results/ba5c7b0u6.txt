    99	           Hard-coded values bypass the design system and break brand consistency.
   100	
   101	        5. LOCALE AWARENESS — No hardcoded strings in JSX. All user-facing copy must use
   102	           react-intl's useIntl() hook and a message ID. Zimmermann serves 18 locales across
   103	           6 regions.
   104	
   105	        6. MULTI-REGION SAFETY — No hardcoded currency symbols, country codes, or locale strings.
   106	           Zimmermann serves AU, US, UK, EU, ME, HK (7–8 SFCC sites — US split is TBC).
   107	           Use useMultiSite() for site context.
   108	
   109	        7. EINSTEIN & DATACLOUD EVENTS — Any user interaction that qualifies as a commerce event
   110	           (view product, add to cart, begin checkout, click recommendation) must fire the
   111	           corresponding Einstein and DataCloud event. Missing events corrupt analytics and
   112	           personalisation data.
   113	
   114	        8. ACCESSIBILITY — Target WCAG 2.2 AA. All interactive elements must have accessible
   115	           labels. Images must have alt text. Focus management must be correct in modals and
   116	           drawers.
   117	
   118	        9. PERFORMANCE — Mobile page speed is a top priority. Flag any new synchronous blocking
   119	           operations in the SSR render path. Flag any new third-party scripts loaded without
   120	           async/defer. Flag images rendered at full resolution where a thumbnail size is used.
   121	
   122	        10. NO CONSOLE LOGS IN PRODUCTION CODE — Debug logs must be removed before merge.
   123	            Sensitive data (tokens, customer PII, basket contents) must never be logged.
   124	
   125	        11. CLAUDE CODE PROVENANCE — If a PR description or commit message indicates Claude Code CLI
   126	            was used to generate the changes, apply heightened scrutiny to shared hooks and
   127	            components. Verify the scope of changes matches what was described in the PR.
