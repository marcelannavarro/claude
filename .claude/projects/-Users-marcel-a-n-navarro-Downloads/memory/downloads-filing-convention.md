`~/Downloads` is an organized working archive, not a staging area — Marcel chose to organize
in place rather than relocate to `~/Documents`. The convention is documented in
`~/Downloads/.claude/CLAUDE.md`, which is the authoritative version; read that first.

Structure: `_Inbox/` (landing zone for anything new), `_Review/` (unresolved conflicts +
`manifest.md`), `Zimmermann-PWA/` (active project, category subfolders), `Playbooks/`
(team-facing docs), `Learnings/` (personal notes), `Accenture-Admin/`, `Personal/`,
`Media/Images/`, `Pre-Zimm/` (closed archive — don't file new work there).

The one rule: **nothing stays loose at the root.** Screenshots go to
`<Project>/Screenshots/` keeping the macOS date-stamped name. Ticket docs go to
`<Project>/TSDs/SFCC-<n>/`.

Reorganized 2026-08-22 from ~50 loose root files. See [[file-organization-preferences]] and
[[marcel-companion-doc-habit]].
