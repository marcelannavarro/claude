Marcel routinely writes the **same topic twice on purpose**: one detailed/technical version
and one plain-language companion. Suffixes vary — `-eli5`, `-plain`, `-detailed`, `LEARNING`,
or just a different title ("Spike Findings" vs "Learning Notes").

These look like duplicates by filename and are **not**. During the 2026-08-22 reorg, 4 of 5
suspected duplicate pairs turned out to be intentional companions; only `tagging.md` /
`tagging copy.md` was a real conflict.

**How to apply:** before flagging two similarly-named docs as duplicates, read the first
heading of each. A "plain-English version" / "eli5" / "the simple version" subtitle means
it's a companion — file both, don't dedupe. He learns by re-explaining things simply, so
these pairs are the point, not clutter. See [[file-organization-preferences]].
